# 山野有栗 · 商户商品与库存演示

React 18 + TDesign React + ECharts 的单店商户前端。所有经营、订单、库存和账目均为虚构样本；无真实支付、平台核销、账号或用户资料采集。微信/抖音/美团均待授权。推荐奖励 10% 仅为未确认的示例。

## 本轮功能

- 商品管理：图片、分类、库存类型、多规格 SKU、价格与计价单位、上下架及售罄；支持搜索筛选、详情、新增/编辑、取消和批量上下架。
- 库存管理：逐 SKU 展示在库、订单占用和可售；可售 = 在库 − 占用。称重水果以整数克存储、kg 显示、元/斤计价；独立包装按盒/瓶等计数；预约票共享日期场次名额，不能跨单位合计。
- 补货、报损和盘点需填写原因，保留前后值与流水；拒绝负库存、在库低于占用、过期库存版本；低库存及缺货独立提示。
- 模拟商品订单：创建预占、模拟收款、提货出库；未履约取消释放占用；已交付生鲜退款只冲回账目，不自动回补库存。预约票核销不再次扣名额。
- 保留工作台、入园订单、验券/撤销、称重收款、饮品制作、预约容量、账目、奖励、流量及岗位演示视图；新增库存页，共 12 个页面。

本机 localStorage 保存演示状态，沿用旧存档键并迁移旧数据。前端岗位限制不是生产鉴权，也没有多人服务器同步。可在“接入与设置”中重置样本。商品图片为原创 SVG 示意插画；本地自选图片只存当前浏览器，不上传。

## 运行和构建

需 Node.js 20.19+ 或 22.12+（本次使用 Node 24）。

```sh
npm ci
npm run dev
npm run build
```

开发入口 `http://127.0.0.1:18827/`。构建输出 `dist/`，`base: './'` 和 hash 路由支持 GitHub Pages 子目录。可运行 `node preview-server.mjs` 预览已构建文件；端口占用会退出，不停止其他服务。

发布目录为仓库 `demos/merchant/`；可维护源码位于 `sources/merchant/`。构建后只复制 `dist` 文件到发布目录，保留该目录原有文件和其他项目。源码无私密配置、凭据或真实客户数据。

## 快速演练

商品管理搜索“盒装”，查看 125g/250g/500g 三种独立 SKU；进入详情，调整库存并填写原因，再查看流水。创建模拟商品订单后，在“订单管理 → 商品订单”中演示模拟收款、提货或取消，核对占用变化。

原采摘流程：验券查询 `SY1001` → 确认演示核销 → 称重。毛重 1.850kg、皮重 0.150kg、40元/斤，应收136元，采摘净重同时从现场鲜采库存扣减。
